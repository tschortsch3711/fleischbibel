# Zusammenkünfte

Zusammenkünfte sind der eigentliche Zweck der Fleischgemeinschaft.

## Grundablauf

1. Jemand schlägt ein Treffen oder einen Zeitraum vor.
2. Die Verfügbarkeit wird geklärt, vorzugsweise über Fragab.
3. Ort, Uhrzeit und grober Rahmen werden festgelegt.
4. Aufgaben wie Einkauf, Grill, Getränke oder Beilagen werden freiwillig verteilt.
5. Wer zugesagt hat, erscheint oder sagt rechtzeitig ab.

## Erwartung

Zusammenkünfte müssen nicht perfekt sein. Sie sollen stattfinden, schmecken und allen Beteiligten zumutbar organisiert sein.

| Thema | Erwartung |
| --- | --- |
| Zusage | Verlässlich oder rechtzeitig korrigiert |
| Einkauf | Vorher grob abgestimmt |
| Kosten | Transparent und pragmatisch geteilt |
| Hilfe | Freiwillig, aber willkommen |
