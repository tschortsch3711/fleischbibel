# Regeln

Diese Regeln sollen nicht verkomplizieren, sondern vereinfachen.

Sie sorgen dafür, dass Termine, Erwartungen und Zuständigkeiten klar bleiben. Die Fleischgemeinschaft braucht keine Satzung mit Siegelwachs, aber ein paar verlässliche Grundsätze.

## Kurzfassung

- Respektvoll bleiben.
- Termine klar kommunizieren.
- Zusagen ernst nehmen.
- Rechtzeitig absagen.
- Freiwillig helfen.
- Nichts zerreden.
- Fleisch nicht unnötig verkomplizieren.

::: warning Wichtig
Regeln ersetzen keine gute Laune. Sie verhindern nur, dass schlechte Organisation sie auffrisst.
:::
