# Die Fleischgemeinschaft

Die Fleischgemeinschaft ist ein freiwilliger Zusammenschluss gleichgesinnter Fleischliebhaber.

Im Mittelpunkt stehen:

- Fleisch
- Grillen
- Gemeinschaft
- gute Gespräche
- freiwillige Organisation
- regelmäßige Zusammenkünfte

Die Gemeinschaft ist dezentral organisiert. Niemand ist automatisch verantwortlich, nur weil er etwas angestoßen hat.

Jedes Mitglied kann Ideen einbringen, Treffen vorschlagen oder organisatorisch helfen. Wer etwas übernimmt, verdient Unterstützung. Wer nichts übernehmen kann, bleibt trotzdem Teil der Gemeinschaft.

::: info Leitgedanke
Die Fleischgemeinschaft lebt von Beteiligung, nicht von Dienstplänen.
:::
