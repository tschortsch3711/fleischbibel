# Monatliche Abfrage

Die monatliche Abfrage dient dazu, mögliche Termine früh sichtbar zu machen.

## Ablauf

1. Eine neue Abfrage wird erstellt.
2. Der Link wird in WhatsApp geteilt.
3. Mitglieder tragen ihre Verfügbarkeit ein.
4. Aus den Antworten wird ein sinnvoller Termin vorgeschlagen.
5. Details werden danach gemeinsam geklärt.

Die Abfrage ist kein Vertrag, aber ein ernst gemeinter Hinweis auf mögliche Teilnahme.

::: warning Bitte eintragen
Wer regelmäßig nicht antwortet, erschwert die Planung. Keine Antwort ist keine geheime Zusage.
:::
