# Entscheidungen

Entscheidungen sollen pragmatisch getroffen werden.

## Gute Entscheidungen

- sind klar formuliert
- lösen ein konkretes Problem
- respektieren freiwillige Beteiligung
- lassen sich mit vertretbarem Aufwand umsetzen
- werden nicht unnötig zerredet

Nicht jede Frage braucht ein Grundsatzurteil. Manchmal reicht: Wer kann, macht. Wer mitisst, beteiligt sich angemessen.

::: tip Entscheidungsmaßstab
Wenn eine Lösung funktioniert, fair ist und Fleisch ermöglicht, ist sie meist ausreichend amtlich.
:::
