# Kein Oberhaupt

Die Fleischgemeinschaft hat kein Oberhaupt.

Das bedeutet:

- Niemand entscheidet dauerhaft für alle.
- Niemand ist automatisch verantwortlich.
- Niemand wird durch häufige Initiative zum Pflichtorgan.
- Entscheidungen entstehen aus Vorschlägen, Zustimmung und praktischer Umsetzbarkeit.

::: info Merksatz
Initiative ist willkommen. Dauerzuständigkeit entsteht daraus nicht automatisch.
:::
