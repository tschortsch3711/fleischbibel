# Rollen

Rollen können für einzelne Treffen hilfreich sein. Sie sind freiwillig und zeitlich begrenzt.

## Mögliche Rollen

| Rolle | Aufgabe |
| --- | --- |
| Terminwächter | Achtet auf Abfrage, Fristen und Rückmeldungen |
| Grillverantwortlicher | Kümmert sich für ein Treffen um Grill, Kohle oder Technik |
| Einkaufsbeauftragter | Besorgt abgestimmte Mengen und behält Kosten im Blick |
| Beilageninstanz | Koordiniert Brot, Salate, Saucen oder sonstige Begleitung |
| Chronist | Hält besondere Ereignisse für die Chronik fest |

Rollen sind keine Ämter. Nach dem Treffen fallen sie automatisch wieder in den Zustand allgemeiner Freiheit zurück.
