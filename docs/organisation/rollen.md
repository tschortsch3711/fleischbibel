# Freiwillige Beiträge

Freiwillige Beiträge erleichtern Treffen. Sie sind keine Ämter, keine Pflichtrollen und keine dauerhaften Zuständigkeiten.

Wer einmal hilft, bleibt dadurch nicht automatisch zuständig.

## Mögliche Beiträge

| Beitrag | Worum es geht |
| --- | --- |
| Termin anstoßen | Einen Vorschlag machen oder auf ein freies Zeitfenster im Fleischkalender hinweisen |
| Ort vorschlagen | Einen privaten, öffentlichen oder anderweitig geeigneten Ort ins Spiel bringen |
| Grillmöglichkeit klären | Prüfen, ob und wie gegrillt werden kann |
| Einkauf anbieten | Freiwillig etwas für mehrere besorgen, wenn das sinnvoll und abgestimmt ist |
| Getränke oder Beilagen anbieten | Freiwillig etwas ergänzen, ohne daraus eine Pflicht für andere abzuleiten |
| Fleischmeldeamt pflegen | Die monatliche Abfrage erstellen oder aktualisieren |
| Fleischbibel pflegen | Dauerhafte Regeln, Hinweise und Begriffe aktuell halten |
| Kosten klären | Ausgelegte Kosten transparent und fair auf die anwesenden Fleischlinge verteilen |
| Aufräumen mittragen | Nach dem Fleischgelage gemeinsam Ordnung schaffen |
| Chronik pflegen | Besondere Ereignisse knapp und ohne private Details festhalten |

## Grundsatz

Beiträge entstehen aus Möglichkeit, nicht aus Erwartung.

Wer etwas anbietet, hilft der Fleischgemeinschaft. Wer nichts anbieten kann, bleibt trotzdem Teil der Fleischgemeinschaft.
